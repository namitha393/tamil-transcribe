# How to correct the 3 sections (about 15 minutes of audio in total)

Each section has an audio file (`.wav`) and a draft transcript (`.txt`) made by a computer.
Please listen and **fix the text so it matches exactly what was said**.

1. **Write what was said, not what should have been said.** Keep spoken forms
   (பண்ணணும், இருக்கு, போட்டாச்சு), fillers (ம், ஆமா, ஐயா), repeated words, and unfinished words.
2. **Fix every wrong word**, especially astrology terms (planets, signs, stars, உச்சம், நீச்சம், ஆட்சி…).
3. **English words: write them in Tamil letters as they were spoken** (சார், ஓகே, கரெக்டா).
   This keeps the scoring fair. (The English-letters style is a separate question.)
4. **Numbers: write them as words** (பத்து, not 10).
5. **Attendees and quiet voices count too** — if you can hear it, write it. If a word is truly
   impossible to make out, write `[?]`.
6. Keep the `[12.3s]` time marks at the start of lines; you may join or split lines freely.
7. No punctuation needed.

Each section: Section A = normal teaching, B = heavy on astrology terms, C = discussion with attendees.
Expect about 30–45 minutes of work per section. Thank you!
